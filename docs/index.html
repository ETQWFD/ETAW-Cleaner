FEATURES

六大能力，真实可用

不是演示，扫描、卸载、清理、记录每一步都是真实的。

第三方应用扫描

扫描全部第三方应用，列表清晰展示每个应用的名称、包名、安装时间与官方网站。

双重验证卸载

点击应用弹出卸载询问，二次验证确认后执行卸载，系统级通道再确认一次，杜绝误删。

残留深度清理

扫描 /data 与 /sdcard 下与卸载应用相关的数据目录、缓存、OBB 等残留，配合 Shizuku 权限真正删除。

SHA-256 回收站

卸载信息经 SHA-256 哈希计算后记入本地回收站，保存安装时间、官网等完整信息，可随时查找。

主题与多语言

内置跟随系统 / 浅色 / 深色三档主题，支持简体中文、English、繁體中文三种语言即时切换。

检查更新

设置内一键检查更新，直连 GitHub Release 获取最新版本并跳转下载，官网下载同样同步最新版。

HOW IT WORKS

三步完成一次干净卸载

1

扫描第三方应用

打开应用自动扫描，按名称列出所有第三方应用，展示安装时间与官方网址（长按可搜索未收录的官网）。

2

双重验证后卸载

点击目标应用 → 弹出卸载询问 → 二次验证确认 → 执行真实卸载（Shizuku 授权下静默卸载，否则走系统确认通道）。

3

清理残留并记录

自动扫描并删除该应用相关残留文件，卸载信息经 SHA-256 指纹记录进本地回收站，需要时随时找回官网重新下载。

下载 ETAW清理

APK 安装包已签名，可直接安装。页面下方版本与下载链接实时从 GitHub Release 获取，与 App 内「检查更新」保持一致。
